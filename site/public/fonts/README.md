# Self-hosted web fonts

Vendored so the site makes **zero third-party requests** (no calls to
`fonts.googleapis.com` / `fonts.gstatic.com`).

| Family | Weights | Subsets | License |
|---|---|---|---|
| Inter | 300, 400, 500, 600, 800 | latin, latin-ext | [SIL Open Font License 1.1](https://openfontlicense.org) |
| JetBrains Mono | 400, 500, 600 | latin, latin-ext | [SIL Open Font License 1.1](https://openfontlicense.org) |

Source: Google Fonts. To refresh, re-download the `woff2` files for the same
families/weights and keep `fonts.css` in sync.
